Banking System using C and File Handling
💻 Tech Stack: C programming, File I/O
📂 Database: File-based (text files)
I developed a basic banking system using the C programming language with a text-based interface running in the terminal. The system allows users to register, log in, view their balance, deposit and withdraw money.
✔ Key Features:
- User registration
- User login system
- Balance inquiry
Deposit and withdrawal transactions
🔐 All user data is stored and managed through text files without using a traditional database system. Through this project, I gained hands-on experience with file operations in C and structured programming.
